# US-12 — GitHub Repository Setup

| Veld | Waarde |
|---|---|
| ID | US-12 |
| Titel | GitHub repository public maken met MIT License |
| Rol | Developer |
| Afhankelijk van | US-00 |
| Status | Open |
| Prioriteit | **P2 — Medium** |
| Geschatte effort | 15 minuten |

## Verhaal

Als developer wil ik de SOC-Analyst code op GitHub publiceren met een MIT License, zodat anderen de app kunnen gebruiken, bijdragen en van de code kunnen leren.

## Doel

1. Voeg MIT License toe aan project
2. Initialiseer GitHub repo (indien nog niet gedaan)
3. Push naar GitHub
4. Update README met GitHub badges

## Acceptatiecriteria

- [ ] MIT License bestand (`LICENSE`) toegevoegd
- [ ] GitHub repo aangemaakt (public)
- [ ] Code gepusht naar GitHub
- [ ] README bijgewerkt met GitHub URL
- [ ] Git commit gemaakt

## Definition of Done

- [ ] LICENSE bestand met MIT License tekst
- [ ] GitHub repo exists en is public
- [ ] Alle commits gepusht
- [ ] README bevat GitHub badge en URL
- [ ] Git commits gemaakt
